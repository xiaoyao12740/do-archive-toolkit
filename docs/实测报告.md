# 实测报告 / Test Report

记录 do压缩包 V5（Windows + Android）的实测环境与用例结果，供使用者判断可用性，也便于回归。

---

## 一、Windows 端
### 实测环境
| 项 | 值 |
|---|---|
| 操作系统 | Windows 11 专业版（Windows 10 同样兼容，虚拟机方案覆盖） |
| Python（脚本/打包） | 3.13.16 |
| 打包器 | PyInstaller 6.22.3（--onefile） |
| 7-Zip | 随包绿色版；并在 `C:\Program Files\7-Zip`、`C:\Windows\system32\7z.exe` 验证 |
| WinRAR | 已安装 `C:\Program Files\WinRAR`（Rar.exe / WinRAR.exe） |
| lz4 | 随包 `windows\tools\lz4\lz4.exe` |

### 实测用例与结果
| # | 用例 | 结果 |
|---|---|---|
| 1 | 压缩文件夹为 AES/加密 7z（带密码 + 加密文件名） | ✅ 通过 |
| 2 | 压缩为 zip（无密码） | ✅ 通过 |
| 3 | 外层 zip 内套加密 7z，一次递归解压到底（含密码） | ✅ 通过，2 层均成功 |
| 4 | 中文目录名 / 中文文件名（"子目录/b.txt"） | ✅ 通过，无乱码 |
| 5 | exe 形态命令行压缩 | ✅ 通过（控制台捕获中文乱码仅是抓取编码问题，bat 已 chcp 65001） |
| 6 | 随包 7z/lz4 工具自探测（无系统安装也能跑） | ✅ 通过（tools 优先） |
| 7 | PyInstaller 单文件 exe 构建 | ✅ 通过，约 8.45 MB |

### 建议你做的干净机验证
在不装 Python/7-Zip 的全新 Win10/11 虚拟机里，仅凭 `do压缩包.exe + tools/` 复测
压缩→删除原件→带密码解压还原、lz4、分卷 rar（步骤见 `WINDOWS_使用教程.md` 第八节）。

## 二、Android 端（v1.4.8）
### 实测设备
| 维度 | 覆盖 |
|---|---|
| 系统 | Android 14、Android 17 |
| SoC 平台 | 高通骁龙（Snapdragon）、联发科天玑（Dimensity） |
| 模拟器回归 | Android Studio 模拟器 API 34 |

### 实测用例与结果
| # | 用例 | 结果 |
|---|---|---|
| 1 | 批量解压（单文件 / 整个目录两种入口） | ✅ |
| 2 | AES-256 加密 zip、7z | ✅ |
| 3 | rar / 分卷（partN.rar、7z.001 等） | ✅ |
| 4 | lz4 极快单层解压 | ✅ |
| 5 | 多层套娃递归 + 结果扁平化 | ✅ |
| 6 | 密码本：在加密本页加只进加密本 / 解密本页同理 | ✅ |
| 7 | 密码复制到另一本 + 同本唯一性去重（重复被拦） | ✅ |
| 8 | 12 主题全页面联动；夜间黑↔其它反复切按钮不残留 | ✅ |
| 9 | 5 内置图标经 activity-alias 切换（桌面组件确认变化） | ✅（天玑桌面刷新有延迟，系统行为） |
| 10 | 日志导出（详细 + 简略） | ✅ |
| 11 | 覆盖安装升级保留密钥与设置 | ✅ |

### 已知系统行为（非缺陷）
- 天玑等机型的系统桌面启动器对"应用图标切换"刷新有延迟，可在"应用信息"先看到，或重启后刷新；
- Android 平台不允许把任意照片设为桌面启动器图标（图标须为编译期内置资源），仅支持内置 5 选 1。
