# Android 端使用教程（中文 · 图解版）

> 适用：do压缩包 v1.4.8 · 已实测 **Android 14 与 Android 17（骁龙 / 天玑平台）**。

---

## 一、它能做什么
- 批量解压、批量压缩；支持 zip（AES-256）、7z、rar、tar、gz、bz2、xz、lz4
- 分卷（part1.rar / z01 / zip.001 / 7z.001）整组处理
- 多层"套娃"自动递归解压；结果扁平化（内容 + 第一个包名目录，不堆嵌套）
- 加密本 / 解密本双密码本：分组管理、相互复制、SQLite 唯一去重
- 12 种主题全页面联动（默认紫、夜间黑、护眼绿、牛皮纸、蓝、青碧、樱粉、暖橙、朱红、月灰、薄荷、奶油）
  + 自定义背景图片 / 自定义字体颜色；夜间黑下按钮与字体自动降亮度
- 工作调度：低 / 中 / 高 / 自动（按设备实时情况）/ 自定义并发数（1–16）
- 解压 / 压缩目标都**既能选单个文件，也能选整个目录**
- 成功后删除原包 / 原文件（默认关，随时可调）
- 详细 + 简略日志导出；后台通知显示当前包名与进度
- 5 款内置应用图标，可切换为桌面启动器图标
- 中英文双语

## 二、安装（Android 14–17 通用）
1. 把 `android/do压缩包_v1.4.8.apk` 发到手机（微信文件传输、数据线、网盘均可）；
2. 在手机上点开 apk；首次会提示"为了你的安全，禁止安装未知来源应用"：
   - 点 **设置 → 允许来自此来源的应用**（不同品牌叫"安装未知应用/外部来源应用"），返回继续安装；
3. 安装完成打开，按需授予**文件 / 所有文件访问**权限（批量处理存储文件必需）；
4. **覆盖安装升级**：直接装新版即可，已保存的密码本、设置会保留，不用重新输密钥。

> 各品牌入口略有差别：一般在 `设置 → 应用 → 特殊权限 → 安装未知应用`，
> 或弹窗里点"仍要安装 / 继续安装"。本应用不申请联网权限，可离线使用。

## 三、解压（图解流程）
```
① 选择解压目标
   [ 选择压缩包 / 目录 ]   ←─ 可点选单个包，也可选整个文件夹
   未选择
   [ 开始解压 ]            ←─ 主按钮
② 工作调度
   占用运存 / 并发档位：[低][中][高][自动]
   ☐ 解压成功后删除原压缩包（防误删，默认关）
   档位：自动 ｜ 成功即删原包：关
③ 解压进度与日志
   进度条 + 当前包名；完成后可导出详细/简略日志
```
1. 点「选择压缩包 / 目录」，选一个包或一整个文件夹；
2. 选调度档位（一般用**自动**即可，低配手机可选低/中）；
3. 需要就勾"成功后删除原压缩包"；
4. 点「开始解压」。加密包会弹出输入密码；密码可存入密码本下次自动带。
5. 分卷、套娃会自动处理，最终内容放在以第一个包命名的文件夹里。

---

## 四、压缩
1. 顶部点「压缩功能 / SETTINGS」旁的压缩入口，进入压缩页；
2. 选要打包的文件或目录（同样单文件 / 目录都可）；
3. 选加密方式：不加密 / 部分加密 / 全部加密（加密 zip 用 AES-256）；
4. 设堆叠层数、密码、并发档位、输出位置；
5. 开始压缩，进度与结果在同页展示。

---

## 五、密码本（加密本 / 解密本）
- 底部「密码」进入。顶部可切换**加密本 / 解密本**两本；
- **在哪个页面添加，就加进哪一本**（在解密本页加的只进解密本，反之亦然）；
- 点某条密码的「移入加密本 / 移入解密本」是**复制**语义（原条目保留），
  成功后有浅色小提示"已复制到 XX 本"并自动消失；
- 同一条密码在同一本内**唯一**，重复会被拦截，不会重复添加；
- 数据库本地存储（Room/SQLite），不上传。

## 六、主题与外观
- 「设置 /SETTINGS → 主题颜色」12 选 1；切换后**解压、压缩、设置、密码本全部页面**统一联动；
- 「夜间黑」：背景近黑、按钮与字体自动调暗不刺眼；切回其它主题会正确恢复，不会残留黑色按钮；
- 「自定义」可设背景色，「选择背景图片」可设图片背景，「自定义字体颜色」可调字色；
- 顶部标题栏采用与主题相近的磨砂效果，跟随主题变化；背景有斜向浅灰"do压缩包"水印。

---

## 七、应用图标（桌面图标）
- 「设置 → 应用图标」5 个内置预设（岩石 / 主机 / 显示器 / 手机 / 线条小人，默认线条小人）；
- 点选一个，再点「保存并重启」即可设为**桌面/抽屉里的应用图标**；
- ⚠️ 安卓桌面（启动器）图标刷新有延迟，尤其**天玑系**机型可能要稍等片刻，
  或"长按应用 → 应用信息（详情）"里先看到新图标；重启手机后必定刷新。
- 受安卓系统限制，桌面图标只能在这几个内置预设间切换，不能用任意自定义照片（App 内不做误导）。

## 九、常见问题 FAQ
**Q：升级后密码没了？**
A：请用**覆盖安装**（不要先卸载）。覆盖安装会保留数据库；卸载会清除应用数据。

**Q：后台解到一半被杀？**
A：在系统设置给本应用"允许后台运行 / 关闭省电优化 / 自启动"权限（国产 ROM 常见）。

**Q：桌面图标没变？**
A：是桌面启动器缓存延迟（天玑明显），稍等或重启手机；应用信息里能先看到新图标。

**Q：能完全离线吗？**
A：能。核心解压压缩全部本地完成，本应用不申请联网权限。

## 十、构建（开发者）
- Android Studio 工程源码位于 `android/source/`（Kotlin + Gradle）；
- 用 Android Studio 打开 `source/` 目录，等待 Gradle 同步后 `Build → Generate Signed APK`；
- 原生层依赖 libarchive / unrar（JNI），签名 keystore 需自备；详见 `docs/实现原理.md`。
